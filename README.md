## 🚀 Featured Projects

### 🎉 Festify — IoT-Enabled Event Ticketing Platform  
🔗 [GitHub](https://github.com/AbhishekRajoria/Festify) · 🌐 [Live Demo](https://festify-tau.vercel.app)

- Dual-mode check-in: QR browser scans (html5-qrcode) and ESP8266 + RC522 RFID taps hitting the same /api/tickets/verify endpoint
- Auth migrated from localStorage JWT to httpOnly cookie + Bearer fallback; same-origin Vite + Express deploy eliminates CORS preflight
- Mongoose connection cached on global._mongoose for serverless warm-reuse across 11 TanStack Query pages
- Role-based access for organizers and attendees with event lifecycle management
- Cloud media pipeline via Multer + Cloudinary for image uploads

**Stack:** React 19 · Vite · Tailwind CSS · Express · MongoDB · Mongoose · JWT · Cloudinary · TanStack Query · ESP8266/RC522

**✨ Innovation Highlights:**
- **Dual-mode Check-in**: Same API endpoint handles both QR browser scans and ESP8266 RFID UID taps
- **Serverless-Ready**: Mongoose connection cached for cold-start reuse; ~200 LOC removed by standardizing on TanStack Query
- **Single Vercel Deploy**: Vite SPA + Express as one Vercel project — no CORS, fast cold starts

### 📊 MarketPulse — Stock Analytics SPA with AI Assistant  
🔗 [GitHub](https://github.com/AbhishekRajoria/MarketPulse) · 🌐 [Live Demo](https://market-pulse-two.vercel.app)

- AI assistant powered by Google Gemini 2.5 Flash via Vercel AI SDK with 3 tools (portfolio summary, stock quotes, symbol search) — streaming responses with inline tool-call chips
- Real-time stock charting with multiple timeframes (1D, 1M, 1Y, ALL)
- Customizable watchlist with live price updates and portfolio performance tracking
- Server-side LRU cache with namespace TTLs extending free API quota ~10×
- OKLCH-based light/dark theming with unified amber accent palette
- JWT authentication with persistent theme preferences

**Stack:** React 19 · Zustand · TanStack Query · Vite · Express 5 · MongoDB · Vercel AI SDK · Gemini 2.5 Flash · Chart.js

**✨ Key Highlights:**
- **AI Assistant**: Gemini-powered agent grounded in user's portfolio data with tool-calling, streaming via Vercel AI SDK
- **Cache Layer**: LRU cache with per-namespace TTLs (60s quotes / 5min charts / 1h search) — hit rate exposed at /api/stock/_cache-stats
- **Single Vercel Deploy**: React 19 SPA + Express 5 as a single Vercel Function via custom path rewrite; sub-second cold start on Fluid Compute
